# DS-A3 result summary (platform submission)

This project evaluates interpretable regression baselines for daily bike-sharing demand (`cnt`) using the UCI Bike Sharing daily dataset. The data audit covers 731 observations and records dataset provenance and a checksum. To preserve temporal order, the data were divided chronologically into 511 training observations, 110 validation observations, and 110 held-out test observations. Hyperparameter tuning used training data, model comparisons used validation data, and the test set was not used for model selection.

Linear regression, Ridge, and Lasso candidates were compared with a training-median baseline; a seasonal-naive (same calendar day in 2011) baseline was also evaluated separately. In the reported validation comparison, Ridge with the year indicator (`yr`) achieved MAE 786.386, RMSE 963.466, and R² −0.273. Ridge without `yr` performed substantially worse (MAE about 2,155.726), showing that the year indicator materially changes the validation result. Because the primary feature plan excludes `yr`, the year-indicator model is reported separately as a sensitivity candidate rather than silently replacing the primary specification.

The analysis includes residual and time-order diagnostics, influence checks, heteroscedasticity testing, a learning curve, and validation error slices. The negative validation R² indicates that the selected candidate does not outperform a validation-mean predictor under the usual R² interpretation. Residual dependence and possible heteroscedasticity further limit the model. The findings are predictive, not causal, and same-day weather features may be unavailable for forecasts made before the day starts. The repository includes the notebook, PDF, provenance and split audits, model-comparison outputs, diagnostics, environment record, and reproduction instructions.
